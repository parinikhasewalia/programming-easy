# Expense Tracker

A simple Expense Tracker made using HTML, CSS and JavaScript.

## Features

- Add an expense
- Enter expense amount
- Select an expense category
- Calculate total expenses
- Delete an expense
- Simple and beginner-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The user enters an expense name, amount and category.

When the Add Expense button is clicked, JavaScript creates a new expense item and adds its amount to the total.

The Delete button removes the selected expense and subtracts its amount from the total.
